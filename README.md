# 서현재

게임 클라이언트 프로그래머입니다. NEXTURE에서 아이러브커피와 마루는 강쥐의 클라이언트(Lua)와 서버(Java)를 함께 개발하고 있습니다.

회사 코드는 공개할 수 없어서, 여기에는 입사 전에 만든 게임과 공부한 내용을 올려 두었습니다.

## 만든 게임

**[The Sword](https://github.com/IO-DOG/TheSword)** (4인 팀, 2024.05 ~ 2025.03)

JRPG풍 던전 크롤러입니다. CSV를 읽어 맵을 깔아 주는 생성 툴과 몬스터 특성 시스템을 만들었습니다. 이후 창업해서 확장 개발하고 itch.io에 출시했습니다. [플레이 영상](https://youtu.be/Swc5I2-JCMQ)

**[MessMath](https://github.com/MessMath/MessMath)** (5인 팀, 2023)

수학 학습 게임입니다. Photon PvP와 UI, 수학 문제 API와 Firebase 연동을 맡았고, 제3회 웅진씽크빅 게임 개발 챌린지에서 개발일지상을 받았습니다. [플레이 영상](https://youtu.be/UUPn5YygFgE)

**[던전포차](https://github.com/Unkown-7/DungeonPocha)** (7인 팀, 2024)

2024 인디크래프트 출품작입니다. 몬스터 최대 100마리가 동시에 오가는 자동 전투를 코루틴으로 만들었습니다.

**[UpToSky](https://github.com/stopresent/UpToSky)** (3인 팀, 2023)

처음 바닥부터 만들어 본 게임으로, Google Play에 출시했습니다. 게임 로직과 UI, 광고를 불러와 보여 주는 흐름을 만들었습니다.

**[종겜스 시뮬레이터](https://github.com/stopresent/nhn-ai2026)** (2026.08)

NAN 2026(NHN 게임 x AI 해커톤) 사전과제입니다. AI 시청자들이 플레이를 보고 채팅으로 반응하고, 그 반응이 점수가 되는 웹 게임입니다. [바로 플레이](https://stopresent.github.io/nhn-ai2026/)

**미니몬퀘스트** (개인, 2026)

세로 화면 2D 횡스크롤 액션 RPG입니다. Steam과 Google Play 출시를 준비하고 있습니다.
